# 차근차근 · 중고차 커뮤니티 첫 버전

A안의 안내형 홈 + B안의 자유로운 구매조건 조절 + C안의 커뮤니티를 결합한 실행 가능한 검토용 서비스입니다. 예시 매물·비용과 사용자가 등록한 콘텐츠를 구분합니다. 실제 중고차 가격 또는 보험 견적 서비스와는 아직 연결하지 않았습니다.

## 선택한 디자인

1안(화이트 + 유칼립투스 그린)을 적용했습니다. 전체 배경·카드·입력창은 흰색, 본문은 차콜, 테두리는 옅은 회색입니다. 녹색 #4C7A68은 주요 버튼·선택 상태·추천 점수에 사용합니다. 시스템 다크 모드에서도 흰 배경을 유지합니다. 구매조건 패널과 안내·추천 영역을 나란히 배치하고 홈의 장식용 사진은 제외했습니다.

## 화면과 흐름

- **내 차 찾기:** 예산·월 한도·주행거리·용도를 조절 → 추천 후보 → 비용과 적합도 이유 확인.
- **매물 둘러보기:** 차종·제조사·가격·연료·지역·연식·주행거리·사고 입력·판매자 유형 검색. 추천 카드의 ‘이 조건의 매물 보기’는 차종과 예산 충족 필터를 적용합니다.
- **찜·비교:** 로그인 후 찜 저장, 2–4대 비교. 보험·연료·세금·정비 대비금·주차·통행·할부를 공통 조건으로 계산합니다. 예시 3대 비교는 로그인 없이 살펴볼 수 있습니다.
- **커뮤니티:** 게시판별 검색, 글·댓글·이미지 등록, 내 글 수정·숨김, 신고·차단, 관련 매물 이동.
- **내 차 팔기:** 사진과 차량 정보 → 참고 호가 자료 확인 → 판매글 등록·수정 → 판매중·예약중·판매완료.
- **내 정보:** 내 판매글·게시글·보낸/받은 문의, 닉네임과 차단 관리. 관리자 계정에는 신고 처리와 수집 상태 화면이 추가됩니다.

데스크톱에는 구매조건 패널을 왼쪽에 배치했습니다. 모바일에서는 ‘조건 변경’을 눌러 패널을 열고, 하단 메뉴로 주요 화면을 이동합니다. 비교 화면은 모바일에서 차량 선택을 바꾸며 읽습니다.

## 설치와 실행

Node.js 22.13 이상, pnpm 11.25를 사용합니다. 아래 명령은 압축을 해제한 프로젝트 폴더에서 실행합니다. Windows/macOS/Linux에서 로컬로 사용할 수 있습니다.

```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_young_sister_grimm.sql
pnpm run dev
```

출력된 로컬 주소로 접속합니다. 일반 로컬 환경에서는 기본 포트가 5173입니다. 첫 실행 시 위 SQL을 한 번 적용합니다. 이미 적용한 SQL은 반복 실행하지 마세요. 로컬 DB·사진은 `.wrangler/state`에 저장됩니다.

일반 로컬 개발 환경에서 로그인 버튼은 개발 전용 계정 `local_seedy`를 사용합니다. 이 모의 로그인은 배포 빌드에 포함되지 않습니다. 현재 배포본은 ChatGPT 계정 인증을 사용하며 소유자 전용입니다. 일반 대중 가입, 국내 본인 인증, 사업자 진위 확인은 후속 구현 대상입니다.

빌드된 Worker를 로컬 확인하려면 `pnpm start`를 사용합니다. 이 모드에는 모의 로그인이 없으므로 개발 UI는 `pnpm run dev`로 확인하세요. 호스팅 환경을 옮길 때 외부에서 인증 헤더를 임의 입력할 수 없도록 인증 게이트웨이 또는 별도 세션 서버가 필요합니다.

## 기술 선택

화면은 React/TypeScript, shadcn UI, Tailwind CSS를 사용합니다. API는 TypeScript Worker, 데이터베이스는 D1(SQLite), 사진 저장소는 R2입니다. Next.js App Router 형태를 Vinext/Cloudflare 빌드 환경에서 실행합니다. 의존성은 `pnpm-lock.yaml`로 고정했습니다.

Java/Spring Boot를 우선 검토했지만, 이번에 바로 열어볼 수 있는 호스팅 환경은 JVM 서버를 실행하지 않습니다. 따라서 검토용 실행본의 API는 TypeScript로 구현했습니다. **Java/Spring Boot 서버는 포함하지 않았습니다.** 운영용 백엔드를 Spring Boot로 전환하려면 아래 API 계약과 데이터 구조를 옮기고 인증·스토리지 어댑터를 교체해야 합니다. 해당 작업을 이미 완료한 것으로 간주하면 안 됩니다.

## 데이터와 계산

- `lib/car-domain.ts`: 가상 샘플, 월 비용·할부·적합도 계산, 호가 비교 기준.
- `lib/validation.ts`: 서버/클라이언트 입력 검증.
- `lib/refresh.ts`: 계약된 데이터 공급처용 수집 어댑터.
- `db/schema.ts`, `drizzle/`: 테이블과 스키마 마이그레이션.
- `app/api/[...path]/route.ts`: 저장·권한·업로드·갱신 API.

니로 DE·아반떼 AD·모닝 JA의 샘플 가격·보험·연비·세금·정비·목적 평가값은 **화면과 계산 흐름을 위한 가상값**입니다. 실제 시장 조사 결과가 아닙니다. 다른 차종은 판매글을 등록할 수 있지만 비용·추천 점수를 만들지 않습니다. 기존 세 모델도 입력 연식·등급별 실제 정밀 비용 모델은 아직 없습니다.

판매가격과 사진·정비 이력 등은 판매자 입력입니다. 자동차 검증 기관 연동이 없으므로 ‘검증 완료’ 표시를 부여하지 않습니다. 사고 정보 미입력을 ‘없음’으로 처리하지 않습니다. 실제 차량 사진이 없는 샘플에는 사진 없음 표시를 사용합니다. 기존 AI 일반 차량 이미지는 파일에 보관되어 있으나 선택한 1안의 홈에서는 표시하지 않습니다.

계산식, 점수 기준, API와 DB 구조, 데이터 확보·후속 작업은 `docs/IMPLEMENTATION.md`를 참고하세요. 검증 기록은 `docs/VALIDATION.md`에 있습니다.

## 환경변수와 14일 갱신

`.env.example`은 변수 이름만 담고 있습니다. 실제 비밀값은 커밋하지 않습니다. 로컬 Worker는 `.dev.vars` 또는 Wrangler가 지원하는 로컬 환경 설정을 사용하고, 배포 환경은 서버의 비밀값 설정을 사용합니다.

- `ADMIN_USER_IDS`: 관리자 사이트 사용자 ID를 쉼표로 구분. 비어 있으면 관리자 기능이 열리지 않습니다.
- `MARKET_DATA_URL`: 이용 허락·저장·표시 조건을 확인한 HTTPS JSON 공급처.
- `MARKET_DATA_TOKEN`: 공급처 인증 비밀값, 필요할 때만 설정.
- `SOURCE_LICENSE_CONFIRMED=true`: 계약과 이용 조건을 확인한 후 설정.
- `REFRESH_SECRET`: 서버 간 갱신용 32자 이상의 무작위 비밀값.
- `SITE_URL`: 별도 일정 실행기에서 호출할 사이트 주소.

수집기는 형식 검사, ID 중복 제거, 3회 재시도, 실행 기록, 실패 시 이전 정상 스냅샷 유지를 구현했습니다. 성공 후 14일이 지나기 전에는 재수집하지 않습니다. 화면에는 기준일·수집일·갱신 지연을 표시합니다.

**현재 외부 공급처, 이용 계약, 실행 일정은 설정하지 않았습니다. 자동 갱신이 실행 중인 상태가 아닙니다.** `scripts/refresh-data.mjs`는 일정 실행기에 등록할 호출 스크립트이며 자체적으로 예약을 만들지 않습니다. 데이터 접근권과 사이트 접근 경로가 확보된 후 매일 실행하도록 연결하면 서버의 14일 주기 검사를 거쳐 격주 수집합니다. 현재 소유자 전용 사이트는 외부 실행기의 접근이 제한될 수 있으므로 인증된 실행 경로도 먼저 마련해야 합니다. 관리자 실패 상태 표시는 있으나 이메일·메신저 알림은 연결하지 않았습니다.

## 구현 상태의 경계

저장 기능과 서버 권한 검사는 동작하도록 구현했습니다. 외부 시세·실거래·보험 견적·리콜·정비 근거 데이터, 범용 차종 카탈로그, 생성형 AI API는 미연동입니다. 현재 설명은 계산 결과로 만드는 결정적 문장입니다. 광고 영역만 마련했으며 광고사 연동·유료 결제·매물 광고 순위는 구현하지 않았습니다.

이 실행본은 선택한 디자인과 핵심 흐름을 검토하기 위한 첫 버전입니다. 요구사항의 모든 운영 기능이 완성되거나 실제 시세 정확도가 검증된 서비스라는 뜻은 아닙니다. 상세 후속 목록을 문서에 남겼습니다.
