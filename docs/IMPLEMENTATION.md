# 구현 기준과 후속 계획

## 비용과 적합도

단위는 금액 만원, 거리 km입니다. 월 현금 지출 = 연 보험 견적÷12 + 월 자동차세 예시 + 연 주행거리÷12÷연비×유가÷10000 + 정비 대비금 + 주차·통행 + 할부 납입금입니다. 보험 견적이 없으면 모델별 가상 범위를 사용합니다. 입력한 동일 견적은 모든 차량에 적용되므로 차량별 실제 견적 확인 안내를 표시합니다. 나이와 보험가입 경력으로 보험료를 임의 확정하지 않습니다.

할부는 차량가격에서 선납금을 뺀 원금에 원리금균등식을 적용합니다. 금리 0%는 원금÷기간입니다. 초기 지출에는 현금 차값 또는 선납금과 가상 취득·등록 비용이 포함됩니다. 감가상각은 포함하지 않아 할부 원금과 중복되지 않습니다. 정비 대비금은 실제 월 청구액이 아닌 예비 적립액입니다.

구매예산은 차량 총가격 또는 초기비용 포함 총가격 기준입니다. 할부에서도 구매 가능한 현금만을 뜻하지 않습니다. 월 상단이 한도보다 높거나 탑승 인원이 좌석 수보다 많거나 판매완료이면 적합 후보에서 제외합니다.

적합도는 다음 값의 중요도 정규화 가중합입니다.

- 비용: clamp(100 − 예상 월 상단÷월 한도×25, 0, 100).
- 사용 목적: 예시 차종별 출퇴근·가족·여행 평가값.
- 공간·주차: 주차 환경에 따라 공간 또는 주차 평가값. 운전 1년 미만이면 주차 평가값과 평균. 4명 이상 사용하는 경차는 공간 점수 40 이하.

광고·결제 여부는 입력이나 계산식에 없습니다. 안전·승차감·성능·연비의 독립 중요도, 주행 환경별 연비 모델, 차종별 보험 견적 입력, 충전비 계산, 공간 치수에 근거한 평가는 후속 고도화 대상입니다. 충전 가능 여부는 저장하지만 현재 전기차 비용 모델이 없어 순위에 적용하지 않는다고 화면에 표시합니다.

## 호가 통계

샘플 매물은 실제 참고 호가 계산에서 제외합니다. 사이트의 실제 사용자 등록 매물 및 계약된 공급처 데이터만 사용합니다. 동일 차종 키·세부등급·사고 입력, 연식 ±1년, 주행거리 ±2만km, 최근 30일 자료를 대상으로 합니다. 사고 미입력, 미식별 차종, 판매완료 내부 매물은 통계를 만들지 않습니다.

ID 중복을 제거하고 IQR 1.5배 바깥 가격을 제외합니다. 유효 표본 10건 미만이면 수치를 만들지 않습니다. 평균·중앙값·25–75백분위 범위·현재 가격 위치·표본 수·출처·가장 오래된 표본 기준일을 보여줍니다. ‘등록 매물 호가’이며 체결가격이 아닙니다. 유사 VIN·사진 중복, 공급처 간 같은 차량 식별, 비정상 매물 탐지, 매물 상태 재확인은 공급처 계약·필드에 맞춰 추가해야 합니다. 현 단계의 사고 비교는 증빙 기반이 아닙니다.

## 데이터 구조와 운영 기본

users(사이트 사용자 ID·별명), profiles(JSON 조건), records(매물/글 메타데이터+JSON), favorites, comments, inquiries, media, blocks, reports, events(빈도 제한), refresh_runs, market_snapshots를 사용합니다. 소유자·상태·게시판·시각은 별도 컬럼과 색인으로 저장하고 상세 입력은 JSON으로 보존합니다. 규모가 커지면 정규화 차종 사전, 검색 색인, 페이지네이션, 별도 사진 수명 관리가 필요합니다. 현재 기록 조회는 최신 500건, 댓글 300건, 문의 100건입니다.

이메일·이름은 별도 DB에 보존하지 않고 사이트 사용자 ID와 닉네임을 사용합니다. 회원 ID는 인증 게이트웨이가 전달한 값만 사용합니다. 입력은 서버에서 Zod로 검사하고 작성·수정·숨김·관리자 API의 소유권을 확인합니다. SQL은 매개변수 바인딩을 사용합니다. 변경 요청은 같은 Origin을 확인하고 분당 사용자 요청을 제한합니다. 이미지 5MB/장·최대10장·PNG/JPG/WebP 서명을 확인하며 SVG를 허용하지 않습니다. 본인 업로드만 첨부할 수 있습니다. 업로드에서 제거한 미첨부 파일은 자동 청소 전까지 남습니다.

반드시 후속 운영 범위로 다룰 항목: 파일 디코딩·리사이즈·EXIF 제거, 바이러스/콘텐츠 검사, 개인정보 처리/삭제·탈퇴, 운영 정책·처리 이력, 문의 답장·알림, 이미지/이벤트 로그 정리, 백업·복구·장애 관측, 사업자/실명 검증, 대량 검색과 동시성, 가격 변경 알림, 악성 사용자 대응. 현재 문의함은 수신·송신 저장 확인까지이며 실시간 채팅은 없습니다.

## 수집 어댑터 계약

공급처가 다음 형태의 JSON을 제공하거나 별도 어댑터가 이 형태로 변환해야 합니다. 아래 도메인은 형식 설명용이며 실제 API가 아닙니다.

```json
{
  "source": "계약된 공급처 이름",
  "sourceurl": "https://example.test/source",
  "observedat": "2026-09-30T00:00:00Z",
  "rows": [{"id":"공급처별-고유키","modelkey":"niro","trim":"1.6 HEV 프레스티지","year":2017,"mileage":110000,"price":1250,"accident":"없음","observedat":"2026-09-30T00:00:00Z","source":"공급처 이름","sourceurl":"https://example.test/listing/1"}]
}
```

JSON 최대 8MB·10,000건. 성공한 스냅샷만 사용하고 오류 시 기존 것을 보존합니다. 데이터 종류별 갱신 일정, 출처별 어댑터와 요금·쿼터, 관리자 외부 알림은 계약에 맞춰 별도 구성해야 합니다. 자동 일정 실행기는 연결 전입니다.
