# 검증 기록

검증일: 2026-09-30. 가상 조건·로컬 데이터베이스를 사용했습니다. 실제 사용자에게 문의·댓글·알림을 보내지 않았습니다.

## 확인한 범위

- TypeScript 정적 검사 통과.
- Worker·브라우저용 코드 빌드 통과.
- 홈 서버 HTML 응답 200, 안내 문구·구매조건·커뮤니티 포함 확인.
- 비용 계산 6개 검사 통과: 무이자/유이자 할부, 월 합계·보험 견적 반영, 예산·인원·판매 상태 제외, 거리·가중치 변화, 시세 표본 부족, 중복·오래된 자료·이상값 제외 후 중앙값과 범위.
- 사진 업로드·본인 임시 조회·미첨부 사진의 외부 조회 거절·다른 사용자의 사진 첨부 거절·게시 후 사진 조회 통과. JSON 이미지 목록을 정확히 조회하도록 수정해 D1 패턴 제한 오류를 해소했습니다.
- 로컬 API 핵심 흐름 통과: 조건 저장 후 재조회, 잘못된 입력 거절, 판매글 등록·가격 수정·이전 가격 보존, 다른 사용자의 수정 거절, 찜 저장, 본인 매물 문의 거절, 문의 당사자만 조회, 글·댓글 등록·수정, 신고 관리자 권한, 차단 적용, 본인 숨김 처리, 비로그인 요청 거절, 다른 Origin 요청 거절.

로컬 요청 시험에서는 테스트용 인증 헤더를 로컬 주소에만 전달했습니다. 테스트 스크립트는 외부 주소를 거부합니다. 배포 환경의 실제 계정 간 로그인은 별도 확인이 필요합니다. 초기 로컬 프록시에서 비로그인/다른 Origin 거절 요청 직후 후속 요청에 재시작 응답이 발생해, 정상 저장 흐름과 거절 검사를 순서대로 분리해 검증했습니다.

## 실행

```sh
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/domain.test.mjs
node tests/run-api-local.mjs
```

API 검증 전 빌드와 로컬 DB 마이그레이션이 필요합니다. 테스트는 로컬 서버를 시작하고 종료하며 검증용 레코드를 만들고 마지막에 글·매물을 숨깁니다. 테스트 계정·문의·신고·이미지는 로컬 DB/R2에 남을 수 있습니다. 배포 DB에는 이 데이터가 포함되지 않습니다.

## 아직 검증하지 않은 범위

환경에서 지원되는 브라우저 자동화가 제공되지 않아 실제 클릭·터치, 화면 너비별 시각 검사, 키보드 전체 동선, 여러 실제 계정의 인증을 브라우저로 검증하지 못했습니다. 반응형 스타일과 레이블을 구현했지만 이를 브라우저 검증 완료로 표현하지 않습니다.

외부 시세·보험·리콜 계약 자료, 데이터 갱신의 실제 공급처, 일정 실행기, 외부 알림은 미연동이므로 실제 연결 시험을 하지 않았습니다. 생성형 AI API는 사용하지 않습니다. WebMCP 도구 2개는 구현했으나 지원 브라우저에서 도구 검색·호출 검증을 하지 않았습니다. 부하·침투·장애 복구 시험은 이번 검증 범위에 포함하지 않았습니다.
